DuoDX SDR recorder. 

A basic Windows 11 command based SDR recorder for long overnight or unattended & scheduled recordings from an SDRplay SDR. Designed primarily for diversity reception with the RSPduo with playback in WavViewDX. It will also work as a single channel recorder with the RSPdx.

Some of the features included are:
* Multiple scheduled recordings. 
* Single and dual channel recordings.
* Ring buffer to avoid dropped samples
* Automatic gap fill with silence, should dropped samples occur
* Real-time console status with signal strength, read and write rates, Ring buffer status
* AGC control while recording
* HTTP remote monitoring (local network only) for monitoring status on your phone or other computer 
* Drive spin up prior to recording
* Post recording file verification
* Independent controls (freq/gain etc) for dual tuners
* No installation required.
* Recorded files can be in Linrad or WavViewDX raw format (single/dual channel) or SDRuno/SDR Connect wav format (single channel only). 
Note: SDRplay API is required to run this. If you have SDRuno or SDR Connect then this will already be on your system.
